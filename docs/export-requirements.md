# Технические требования: экспорт документов в PDF

## Инструмент

`scripts/export_pdf.py` — конвертер markdown → PDF без внешних зависимостей, кроме PyMuPDF (`pip install pymupdf`). Python 3.9+.

## Запуск

```bash
python3 scripts/export_pdf.py <input.md> <output.pdf>
```

Пример (выпуск новой версии манифеста):

```bash
python3 scripts/export_pdf.py ontology/manifest.md dist/UWI_v1.9_Manifest.pdf
```

Результаты складываются в `dist/` (в `.gitignore`, не коммитится).

## Поддерживаемая разметка

- заголовки `#`–`####`;
- абзацы, списки (`-`, `*`, нумерованные), цитаты (`>`), `---`;
- блоки кода ` ``` ` (длинные строки переносятся, см. `PRE_WRAP_WIDTH`);
- инлайн: `**жирный**`, `` `код` ``.

## Оформление

- Формат страницы: A4, поля 50 pt.
- Шрифты: системные macOS (Arial / Arial Bold / Courier New), кандидаты заданы в `FONT_CANDIDATES` внутри скрипта; кириллица поддерживается.
- Шрифты встраиваются в PDF, поэтому файл получается крупным (~2,5 МБ).

## Чек-лист выпуска новой версии

Перед экспортом новой версии синхронно обновить:

1. номер версии в заголовке `ontology/manifest.md`;
2. `ontology/system-prompt.md` (заголовок и блок SYSTEM_PROTOCOL);
3. проверить все миры в `worlds/` на соответствие новой версии онтологии.

Смена версии — только по явному указанию автора (`USER_ROLE: H_author`, см. `ontology/manifest.md`, раздел 4).
