# Технические требования: экспорт документов в PDF

Экспорт выполняется **только по явному запросу пользователя**. Изменение манифеста или его версии не является таким запросом.

## Инструмент

`scripts/export_pdf.py` — конвертер markdown → PDF без внешних зависимостей, кроме PyMuPDF (`pip install pymupdf`). Python 3.9+.

При экспорте `ontology/manifest.md` раздел 4 «Ролевые пресеты» исключается, а в конец документа автоматически добавляется приложение «Открытые вопросы онтологии» из раздела 5 `ontology/questions.md`. Закрытые вопросы не включаются. Эти правила не меняют исходный манифест и экспорт других документов.

## Запуск

```bash
python3 scripts/export_pdf.py <input.md> <output.pdf>
```

Пример (выпуск новой версии манифеста):

```bash
python3 scripts/export_pdf.py ontology/manifest.md dist/UWI_v1.18_Manifest.pdf
```

Результаты складываются в `dist/` (в `.gitignore`, не коммитится).

## Поддерживаемая разметка

- заголовки `#`–`####`;
- абзацы, списки (`-`, `*`, нумерованные), цитаты (`>`), `---`;
- блоки кода ` ``` ` (длинные строки переносятся, см. `PRE_WRAP_WIDTH`);
- инлайн: `**жирный**`, `` `код` ``.

## Оформление

- Формат страницы: A4, поля 50 pt.
- Шрифты: системные macOS (Arial / Arial Bold / Courier New), кандидаты заданы в `FONT_CANDIDATES` внутри скрипта; кириллица поддерживается.
- Шрифты встраиваются в PDF, поэтому файл получается крупным (~2,5 МБ).

## Чек-лист согласованности новой версии

При смене версии синхронно обновить независимо от того, запрошен ли экспорт PDF:

1. номер версии в заголовке `ontology/manifest.md`;
2. `ontology/system-prompt.md` (заголовок и блок SYSTEM_PROTOCOL);
3. упоминания текущей версии в `README.md`, `AGENTS.md`, шаблонах и описаниях миров;
4. при закрытии вопроса — его статус в `ontology/questions.md`;
5. проверить все миры в `worlds/` на соответствие новой версии онтологии.

Любое изменение манифеста требует новой версии и повторной проверки всех миров. Смена версии — только по явному указанию автора (`USER_ROLE: H_author`, см. `ontology/manifest.md`, раздел 4). Добавление миров и правок вне манифеста этой роли не требуют.

Версии v1.12 и v1.15 не имеют отдельных коммитов: изменения v1.12 вошли в коммит выпуска v1.13, изменения v1.15 в коммит выпуска v1.16. Ссылки на v1.12 и v1.15 в манифесте и реестре указывают на эти промежуточные состояния.
