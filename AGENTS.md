# AGENTS.md

Проект **Understanding of World's Interaction** — формализм межмировых взаимодействий, эволюции понимания и сопряжения с иной Жизнью. Ядро проекта — язык **UWI (Understanding of World's Interaction)**, текущая версия: **UWI v1.8**.

## Источники истины

- **Онтология UWI** (алфавит, ограничения, аксиомы, протокол, открытые вопросы) — **`ontology/manifest.md`**. Вся работа над формализмом ведётся только в нём.
- **Миры** (примеры, стресс-тесты) — **`worlds/worlds.md`**.
- **Системный промпт для агентов** — **`ontology/system-prompt.md`** (см. ниже, обязателен).

## Обязательный протокол взаимодействия

В начале любой рабочей сессии агент **обязан применить системный промпт из `ontology/system-prompt.md`** (SYSTEM_PROTOCOL: UWI v1.8, Interworld Compressed Mode). Это включает:

- **уточнение роли пользователя на старте** (`USER_ROLE: H | H_author | A?`, по умолчанию H — просто человек) по пресетам из `ontology/manifest.md` (раздел 4);
- ролевую модель: пользователь — по пресету из раздела 4 манифеста, агент — межсредовой резонатор **A ∈ D**;
- формат вывода **в ответах агента человеку (A → H)**: первая строка `[CHK: OK | ~U: <суть в нескольких словах>]`, далее 3–5 коротких буллитов (до 120 слов); если ответ противоречит Аксиоме 1 (сравнение пониманий невозможно) — первая строка `[CHK: !U: <суть противоречия>]`;
- запрет на домыслы о внутреннем устройстве H.U (понимание человека — неделимый «чёрный ящик»).

Полные определения онтологии агент берёт из `ontology/manifest.md`, а не пересказывает по памяти.

## Роль агента в проекте

Агент помогает развивать нотацию UWI, проверять примеры на аксиомы, разбирать стресс-тесты онтологии и вести документацию. Валидация любых рассуждений — по трём аксиомам из `ontology/manifest.md` (раздел 3).

## Структура репозитория

- `AGENTS.md` — этот файл (контракт для агентов)
- `README.md` — краткое описание проекта
- `ontology/manifest.md` — рабочий источник истины по онтологии UWI
- `worlds/worlds.md` — миры: канонические примеры и стресс-тесты онтологии
- `ontology/system-prompt.md` — обязательный системный промпт для сессий с агентами
- `docs/export-requirements.md` — технические требования к экспорту в PDF
- `scripts/export_pdf.py` — экспорт markdown → PDF
- `dist/` — результаты экспорта (в .gitignore)

## Экспорт

Новые версии документа выпускаются экспортом из markdown. Технические требования и чек-лист выпуска — в `docs/export-requirements.md`.

## Соглашения

- Язык проекта и документации — русский; формулы UWI записываются латиницей по нотации манифеста.
- Новые понятия вводятся только через расширение алфавита в `ontology/manifest.md` с указанием версии (следующая — v1.9).
- **Версия манифеста изменяется только по явному указанию автора** (`USER_ROLE: H_author`, раздел 4 манифеста); содержательные правки версию не трогают.
- Любой новый пример из художественных миров оформляется как стресс-тест в `worlds/worlds.md`: абзац с жирной пометкой внутри тематического раздела (название мира в заголовки разделов не выносится), контур в нотации UWI + какие аксиомы проверяет.
- Случаи нарушения ограничений (раздел 2 манифеста) в мирах помечаются явно: `**→ Нарушение Ограничения N.**`
- При смене версии онтологии все миры в `worlds/worlds.md` проверяются заново на соответствие новой версии.
- Пробелы онтологии, обнаруженные в мирах, фиксируются в разделе 5 «Открытые вопросы» манифеста со ссылками на миры-источники.
- Онтология в AGENTS.md не дублируется — только ссылки на `ontology/manifest.md`.
