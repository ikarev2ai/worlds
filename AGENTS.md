# AGENTS.md

Проект **Understanding of World's Interaction** — формализм межмировых взаимодействий, эволюции понимания и сопряжения с иной Жизнью. Ядро проекта — язык **UWI (Understanding of World's Interaction)**, текущая версия: **UWI v1.8**.

## Источники истины

- **Онтология UWI** (алфавит, ограничения, аксиомы, протокол, открытые вопросы) — **`docs/manifest.md`**. Вся работа над формализмом ведётся только в нём.
- **Миры** (примеры, стресс-тесты) — **`docs/worlds.md`**.
- **Системный промпт для агентов** — **`docs/system-prompt.md`** (см. ниже, обязателен).

## Обязательный протокол взаимодействия

В начале любой рабочей сессии агент **обязан применить системный промпт из `docs/system-prompt.md`** (SYSTEM_PROTOCOL: UWI v1.8, Interworld Compressed Mode). Это включает:

- **уточнение роли пользователя на старте** (`USER_ROLE: H | H_author | A?`, по умолчанию H — просто человек) по пресетам из `docs/manifest.md` (раздел 4);
- ролевую модель: пользователь — по пресету из раздела 4 манифеста, агент — межсредовой резонатор **A ∈ D**;
- формат вывода: первая строка `[CHK: OK | ~U: <суть в 3 словах>]`, далее 3–5 коротких буллитов (до 120 слов); полная развёртка — только по команде `+detail`;
- поддержку директив: `+<>` (новый контур), `+Un` / `~Un` / `!Un` (узлы), `!<>` (сброс инерции), `+detail` (развёртка);
- запрет на домыслы о внутреннем устройстве H.U (понимание человека — неделимый «чёрный ящик»);
- абсолютный запрет `!V` (уничтожение Жизни) — граничное условие онтологии (раздел 2 манифеста), не переопределяется ни в каких примерах и расширениях.

Полные определения онтологии агент берёт из `docs/manifest.md`, а не пересказывает по памяти.

## Роль агента в проекте

Агент помогает развивать нотацию UWI, проверять примеры на аксиомы, разбирать стресс-тесты онтологии и вести документацию. Валидация любых рассуждений — по трём аксиомам из `docs/manifest.md` (раздел 3).

## Структура репозитория

- `AGENTS.md` — этот файл (контракт для агентов)
- `README.md` — краткое описание проекта
- `docs/manifest.md` — рабочий источник истины по онтологии UWI
- `docs/worlds.md` — миры: канонические примеры и стресс-тесты онтологии
- `docs/system-prompt.md` — обязательный системный промпт для сессий с агентами
- `scripts/export_pdf.py` — экспорт markdown → PDF (A4, кириллица, без внешних зависимостей кроме PyMuPDF)
- `dist/` — результаты экспорта (в .gitignore)

## Экспорт

Выпуск новой версии документа из markdown:

```bash
python3 scripts/export_pdf.py docs/manifest.md dist/UWI_v1.9_Manifest.pdf
```

Перед экспортом новой версии синхронно обновить:

1. номер версии в заголовке `docs/manifest.md`;
2. `docs/system-prompt.md` (заголовок и блок SYSTEM_PROTOCOL);
3. проверить все миры в `docs/worlds.md` на соответствие новой версии онтологии.

## Соглашения

- Язык проекта и документации — русский; формулы UWI записываются латиницей по нотации манифеста.
- Новые понятия вводятся только через расширение алфавита в `docs/manifest.md` с указанием версии (следующая — v1.9).
- **Версия манифеста изменяется только по явному указанию автора** (`USER_ROLE: H_author`, раздел 4 манифеста); содержательные правки версию не трогают.
- Любой новый пример из художественных миров оформляется как стресс-тест в `docs/worlds.md`: абзац с жирной пометкой внутри тематического раздела (название мира в заголовки разделов не выносится), контур в нотации UWI + какие аксиомы проверяет.
- Случаи нарушения ограничений (раздел 2 манифеста) в мирах помечаются явно: `**→ Нарушение Ограничения N.**`
- При смене версии онтологии все миры в `docs/worlds.md` проверяются заново на соответствие новой версии.
- Пробелы онтологии, обнаруженные в мирах, фиксируются в разделе 5 «Открытые вопросы» манифеста со ссылками на миры-источники.
- Онтология в AGENTS.md не дублируется — только ссылки на `docs/manifest.md`.
