# «Задача трёх тел» (Лю Цысинь) — закрытое H.U

Цивилизация с прозрачным пониманием сталкивается с закрытым пониманием людей — и космос становится «тёмным лесом».

## Основная часть

Раса Трисолярис мыслит открыто — их понимание прозрачно друг для друга. Столкновение с людьми, чьё понимание закрыто, делает невозможным мгновенный доверительный контакт через космические расстояния и время. Из этого выводится логика «Тёмного леса»: любая цивилизация — потенциальная угроза, поэтому безопаснее уничтожить её превентивно.

Контур:

`E_tri ∈ W/P_trisolaris` с прозрачным `E.U` против закрытого `H.U`; отсутствие `<>` через T -> превентивное `!V`.

Проверка онтологии:

- **Аксиома 1** — ядро сюжета: понимания несравнимы, доверие нельзя измерить, сбой фиксируется только `!`.
- **Ограничение 1** — возведение нарушения в закон выживания.

## Нарушения ограничений

**→ Нарушение Ограничения 1 (`!V`):** превентивное уничтожение чужой Жизни как закон «Тёмного леса».
