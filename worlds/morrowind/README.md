# Morrowind — сон Спящего и обратимые ошибки

Мир, который является сном (симуляцией): его обитатели могут осознать это изнутри, а игрок снаружи совершает обратимые ошибки ради необратимого понимания.

## Основная часть

Мир TES заявлен как сон Спящего — то есть симуляция. CHIM — состояние обитателя, который осознал природу мира изнутри, не выходя наружу, и удержал себя («Я есмь»): осознание обратимости среды без разрушения носителя (Вивек). Снаружи игрок получает тот же контур технически: сохранения и загрузки — буквальный откат локального времени симуляции (`S(M)@t1 -> неудача -> @t0`), обратимые ошибки ради необратимого сдвига понимания игрока.

Сердце Лорхана — след мёртвого бога, объект, меняющий носителей: Трибунал и Дагот Ур получили божественность через контакт с ним; исчезнувшие двемеры оставили только следы (руины, Нумидиум). Активация Нумидиума вызывает Разрыв Дракона — базовое время мира ветвится: одно событие получает несколько противоречивых исходов сразу.

Лор добавляет и нарушение: власть Трибунала основана на убийстве Неревара и присвоении силы Сердца.

Контур:

`E_vivec: осознание S(M) изнутри -> CHIM (удержание E.U)`; `H_игрок <> S(M): @t1 -> !ошибка -> @t0 -> ~H.U`; `E <> M/O [Сердце] -> ~E.U (божественность)`; `M/O [Нумидиум] -> ветвление W@t (Разрыв Дракона)`

Проверка онтологии:

- **Аксиома 2** — две стороны одной симуляции: обитатель осознаёт обратимость изнутри (CHIM), игрок использует её снаружи (загрузки); необратимым остаётся только сдвиг понимания.
- **Аксиома 3** — Сердце как след, дающий силу через контакт; раса исчезла — следы продолжают действовать.
- **Аксиома 2 (нагрузка)** — Разрыв Дракона: необратимое базовое время ветвится, нотация молчит о множественных исходах одного такта.

## Нарушения ограничений

**→ Нарушение Ограничения 1 (`!V`):** убийство Неревара Трибуналом как основание божественной власти.

## Открытые вопросы

Ветвление базового времени (Разрыв Дракона): несколько противоречивых исходов одного такта `W@t` — родственно петлям времени, но без перемещения носителей. Присоединено к Вопросу 3 раздела 5 `ontology/manifest.md` как расширение случая.
