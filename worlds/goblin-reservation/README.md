# «Заповедник гоблинов» (К. Саймак) — открытый узел

**Версия онтологии:** UWI v1.10

Планета становится открытым узлом мирного взаимодействия людей и иных сущностей.

## Основная часть

Земля превращается в заповедник — открытый узел, где люди, сущности из других миров и пришельцы иных планет взаимодействуют через общий контур и артефакты, без разрушения Жизни.

Контур:

`W/P_earth <> [H + E_goblin(M) + E_alien(W/P_x)] <> O_artifact`

## Проверка применимости онтологии

- **Достаточность** — существующих понятий `W/P`, `M`, `H/E`, `O` и `<>` достаточно для описания общего пространства контакта без дополнительных допущений о природе сущностей.
- **Аксиома 1** — выполняется: общий контур не даёт сторонам прямого сравнения `U`; взаимодействие строится через сообщения и следы.
- **Аксиома 3** — выполняется: артефакты служат следами, через которые стороны разных миров изменяют понимание друг друга без копирования `U`.

## Боги

— нет. Гоблины описываются как `E ∈ M`, а не как `G`.

## Суперсущества

— нет. Само происхождение из Другого мира не предполагает `C`.

## Ответы на ключевые вопросы

**→ Ключевой вопрос 1:** `W` и `M` могут сопрягаться через устойчивый узел и артефакты; взаимодействие не требует слияния миров.

**→ Ключевой вопрос 2:** общая среда и доступные следы поддерживают `H <> E` без прямого доступа к чужому `U`.

**→ Ключевой вопрос 3:** долгосрочный контакт возможен при сохранении открытого контура и отказе от `!V`; заповедник задаёт форму такого взаимодействия.
