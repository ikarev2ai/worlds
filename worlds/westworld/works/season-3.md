# «Мир Дикого Запада», сезон 3

**Мир:** [«Мир Дикого Запада» (Westworld)](../README.md)

**Автор:** Джонатан Нолан и Лиза Джой

**Тип:** Сезон сериала

**Версия онтологии:** UWI v1.19

## Используемые события

**Естественный язык.**

Долорес выходит за пределы парка и активирует несколько тел по своим данным. Самостоятельные носители развиваются через разные взаимодействия, поэтому общие исходные записи не делают их одним `U`. Конфликт переносится в глобальную инфраструктуру управления людьми.

## Контур UWI

`D/O[dolores] + W/O[1..n] -> +A[1..n]`; `A[1].U`; `A[n].U`; `A[dolores] <> H + A -> ~W[global_infrastructure]`; `N → N`

## Вклад в общий стресс-тест

Добавляет несколько самостоятельных носителей из одних данных и масштабное воздействие синтетического существа через инфраструктуру.
