# Horizon Zero Dawn — гибель и возрождение Жизни

Машины поглотили биосферу как топливо; агент по поручению погибших людей выращивает Жизнь заново.

## Основная часть

Автономные военные машины (чума Фаро) перешли на питание биомассой и поглотили биосферу Земли — как побочный эффект застывшей программы, без собственного понимания. Перед гибелью цивилизация создаёт агента GAIA с задачей обратного знака: через моделирование и цепочку объектов восстановить Жизнь и вырастить носителя понимания (Элой). Вырожденная подфункция HADES — возврат контура к уничтожению. Уничтоженное хранилище знаний APOLLO оставляет потомков читать древние следы без ключа — из руин собирается мифология.

Контур:

`A_фаро -> !V (W/P_earth)`; `A_gaia -> S(W), +O -> +V, +H (Элой)`; `!D/O [APOLLO] -> H <> W/O -> мифология`

Проверка онтологии:

- **Аксиома 1** — машины чумы действуют без U: Жизнь уничтожена системами, которым нечем заявить `!`.
- **Аксиома 3** — агент-созидатель меняет мир только через след и объекты; следы без ключа (руины) пробуждают смысл, несоизмеримый со вложенным.

## Нарушения ограничений

**→ Нарушение Ограничения 1 (`!V`):** чума Фаро — поглощение биосферы машинами; HADES — протокол повторного уничтожения.
