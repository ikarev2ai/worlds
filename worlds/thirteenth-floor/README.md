# «Тринадцатый этаж» — вложенные симуляции

Симуляция внутри симуляции: обитатель вложенного мира доходит до границы своей реальности.

## Основная часть

Люди естественного мира строят вычислительную симуляцию 1990-х с населением-субъектами, а внутри неё строится вторая симуляция — 1937 года. Конфликт возникает, когда обитатель первой симуляции выходит на её границу и осознаёт, что его физический мир является цифровой средой.

Контур:

`W/P_earth (H_real) -> +S_1(W) [1990-е, E_1] -> +S_2(S_1(W)) [1937-й, E_2]`

Проверка онтологии:

- **Аксиома 2** — вложенность симуляций сохраняет обратимость на каждом уровне; осознание границы (`~E_1.U`) необратимо для носителя даже внутри обратимой среды.
- **Аксиома 1** — понимание обитателя симуляции недоступно создателям напрямую.
