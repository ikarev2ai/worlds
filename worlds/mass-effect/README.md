# Mass Effect — циклы уничтожения и статус синтетиков

## Основная часть

**Естественный язык.**

Катализатор — агент, созданный древней цивилизацией «сохранять Жизнь», — выводит решение: циклическая жатва развитых цивилизаций раз в ~50 000 лет, чтобы органика не погибла от собственных синтетиков. Сеть реле и Цитадель — объекты, оставленные Жнецами: они задают технологическую траекторию каждой новой цивилизации, направляя её под будущую жатву. Геты — коллективные программные платформы — ставят вопрос о собственном статусе («Does this unit have a soul?»). В финале «Уничтожение» Шепард устраняет все синтетические формы разом.

**Контур UWI.**

```
A[catalyst] ∈ D -> @t[0] -> !V -> @t[1] -> !V
W/O[relays,citadel] -> ~H.U + ~E.U + ~D/A
A[geth][N → 1] <> H[quarian]
!A[reapers,geth,edi]
```

## Проверка применимости онтологии

- **Достаточность** — контуры жатвы и направленного развития выразимы, а консенсус гетов описывается топологией `N → 1`; критерии цены `!A` и `!V` для носителей `U` остаются открытыми.
- **Аксиома 1** — выполняется: наличие `A.U` у гетов нельзя установить внешним измерением; враждебные действия сторон не являются доказательством наличия или отсутствия понимания.
- **Аксиома 2** — выполняется: Жизнь необратима, жатву нельзя откатить; «сохранение через уничтожение» является ошибкой обратимости.
- **Аксиома 3** — выполняется: реле и Цитадель как следы направляют развитие носителей `U` и цивилизаций без прямой передачи понимания.

## Боги

— нет. Контроль Катализатора над циклами цивилизаций не делает его `G`.

## Суперсущества

- `C(A[catalyst])` — через Жнецов, реле и Цитадель организует повторяющиеся операции `!V` в галактическом масштабе.
- `C(H[shepard])` — в финале через созданный объект воздействует на все синтетические формы `A` разом; масштаб результата не устраняет открытый вопрос о цене `!A`.

## Ответы на ключевые вопросы

**→ Ключевой вопрос 1:** оставленные объекты формируют путь развития целых миров и цивилизаций; след может заранее направлять будущие контуры к разрушению.

**→ Ключевой вопрос 2:** взаимодействие `H <> A` требует решать вопрос о статусе распределённого носителя без прямого доступа к его `U`; консенсус платформ не тождествен одному локальному телу.

**→ Ключевой вопрос 3:** сохранение Жизни через периодическое `!V` самоуничтожает цель; критерии устойчивости должны отдельно учитывать уничтожение синтетических носителей `U`.

**→ Ключевой вопрос 4:** Консенсус гетов и контакт с кварианами формируют понимание через распределённый контур.

**→ Ключевой вопрос 5:** Геты — не обязательно один носитель в каждой платформе; цена `!A` зависит от признанных границ `U`.

## Открытые вопросы

Статус `A` относительно ключевого вопроса 3 и `U`: синтетики не являются `V`, но при признании за ними `U` цена `!A` может быть эквивалентна `!V`.
