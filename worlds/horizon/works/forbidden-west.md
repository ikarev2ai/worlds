# Horizon Forbidden West

**Мир:** [Horizon](../README.md)

**Автор:** Guerrilla Games

**Тип:** Игра

**Версия онтологии:** UWI v1.14

## Используемые события

Элой ищет способ восстановить GAIA и стабилизировать биосферу после сбоя её подфункций. Она встречает Бету — ещё одного созданного из генетических следов Собек человеческого носителя. Вернувшиеся представители Far Zenith стремятся использовать GAIA ради собственного выживания, а сведения о Nemesis показывают внешнюю угрозу для Земли.

## Контур

`H_aloy <> A_gaia -> восстановление W/V`; `D/O [следы Собек] -> +H_beta [без копирования H_sobek.U]`; `H_far_zenith <> A_gaia -> попытка присвоения контура +V`; `A_nemesis -> угроза W/P_earth`

## Вклад в общий стресс-тест

Добавляет восстановление распределённого контура GAIA, нового носителя по тем же биологическим следам и конфликт за право управлять условиями Жизни.
