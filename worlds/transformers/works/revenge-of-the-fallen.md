# Трансформеры: Месть падших

**Мир:** [«Трансформеры»](../README.md)

**Автор:** Майкл Бэй

**Тип:** Фильм

**Версия онтологии:** UWI v1.19

## Используемые события

**Естественный язык.**

Осколок Оллспарка оставляет в понимании Сэма незнакомые символы и делает его целью десептиконов. Мегатрон возвращается после восстановления тела, а Падший ищет Матрицу для запуска древнего устройства, которое уничтожит Солнце. Оптимус погибает, защищая Сэма. Сэм проходит путь к Матрице, восстанавливает Оптимуса, после чего Оптимус уничтожает устройство и побеждает Падшего с помощью переданных Джетфайром частей.

## Контур UWI

```
W/O[allspark_shard] -> ~H[sam].U
E[decepticon][1..n] -> +E[megatron][restored]
E[megatron] -> !E[optimus]
E[fallen] <> W/O[sun_harvester] -> MAY?(!W/V)
H[sam] <> W/O[matrix] -> +E[optimus][restored]
(E[optimus][original] = E[optimus][restored]) = UNKNOWN
TRANSMIT?(E[optimus][original].U,E[optimus][restored].U) = FALSE
E[optimus][restored] -> !W/O[sun_harvester] + !E[fallen]
```

## Вклад в общий стресс-тест

Добавляет смерть и восстановление Оптимуса, следы знания вне языка людей и угрозу уничтожения звезды как ставку всей земной Жизни.
