# Трансформеры 3: Тёмная сторона Луны

**Мир:** [«Трансформеры»](../README.md)

**Автор:** Майкл Бэй

**Тип:** Фильм

**Версия онтологии:** UWI v1.19

## Используемые события

**Естественный язык.**

Корабль «Ковчег» со Сентинелом Праймом и столпами космического моста обнаружен на Луне. Оптимус восстанавливает Сентинела, но тот раскрывает договор с Мегатроном, убивает Айронхайда и помогает десептиконам захватить Чикаго. План состоит в переносе Кибертрона к Земле и использовании людей для восстановления планеты. Автоботы и люди разрушают мост; Кибертрон гибнет. Оптимус уничтожает ослабленного Мегатрона и отказывается принять власть Сентинела, после чего убивает его.

## Контур UWI

```
H[1..n] <> W/O[ark] -> +E[sentinel][restored]
E[sentinel] -> !E[ironhide]
E[sentinel] + E[megatron] <> W/O[space_bridge]
W/O[space_bridge] -> W/P[cybertron]@W/P[earth]
E[decepticon][1..n] -> !H[1..n] + MAY?(!W/V)
H[sam] + E[autobot][1..n] -> !W/O[space_bridge] + !W/P[cybertron]
E[optimus] -> !E[megatron] + !E[sentinel]
REVERSIBLE?(W/P[cybertron]@t[1],W/P[cybertron]@t[0]) = FALSE
```

## Вклад в общий стресс-тест

Показывает конфликт сохранения родного мира и прав носителей другого: спасение Кибертрона через порабощение людей отвергается, а его окончательная гибель не откатывается победой автоботов.
