# Миры

Каталог стресс-тестов онтологии UWI. Каждый мир — отдельная директория с самодостаточным описанием по шаблону `template.md`. Если мир описан несколькими произведениями одной непрерывной истории, их карточки размещаются в `works/` по шаблону `template-work.md`; общий анализ остаётся в корневом `README.md` мира. Версия онтологии указывается в строке каждого мира и соответствует версии его корневого описания; версии карточек произведений приводятся внутри мира. Аксиомы и ключевые вопросы — в `ontology/manifest.md` (разделы 2–3), открытые и закрытые вопросы — в `ontology/questions.md` (разделы 5–6). При любом изменении манифеста его версия повышается, и все миры проверяются заново.

Добавлять миры и произведения может любой участник, роль `H_author` не требуется. Порядок подготовки и рецензирования изменений описан в [CONTRIBUTING.md](../CONTRIBUTING.md).
