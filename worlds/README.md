# Миры

Каталог стресс-тестов онтологии UWI. Каждый мир — отдельная директория с самодостаточным описанием по шаблону `template.md`. Если мир описан несколькими произведениями одной непрерывной истории, их карточки размещаются в `works/` по шаблону `template-work.md`; общий анализ остаётся в корневом `README.md` мира. Версия онтологии указывается в строке каждого мира и соответствует версии его корневого описания; версии карточек произведений приводятся внутри мира. Аксиомы и ключевые вопросы — в `ontology/manifest.md` (разделы 2–3). При смене версии онтологии все миры проверяются заново.
