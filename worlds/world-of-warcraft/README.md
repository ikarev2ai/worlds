# World of Warcraft — симуляция мира и следы за её пределами

Миллионы людей живут аватарами внутри симуляции Другого мира; события симуляции оставляют необратимые следы в естественном мире.

## Основная часть

WoW устроен двуслойно. Снаружи — люди, входящие в симуляцию художественного мира через аватаров: гибель аватара обратима (возрождение), но время, дружба, гильдии и экономика золота порождают необратимые следы и ставки в реальном мире. Внутри — Азерот: мир с собственными сущностями, где титан Саргерас решает «спасти» вселенную от Бездны, уничтожив всю Жизнь в ней.

Инцидент Corrupted Blood (2005): эффект-«чума» из рейда вырвался в общий мир симуляции и массово убивал персонажей; вспышку остановили откатом симуляции (патч), но само событие стало объектом изучения эпидемиологов в реальном мире — след из симуляции изменил понимание учёных о поведении людей в эпидемиях.

NPC Азерота — программные фигуры без собственного понимания, которым игроки устойчиво приписывают характер и намерения: снаружи носитель неотличим (Лерой Дженкинс — совместный след сообщества, ставший культурным объектом).

Контур:

`H <> S(M/P_azeroth) (аватар обратим, ставки в W@t — нет)`; `S(M): чума -> !аватары -> !S(патч) -> +D/O [событие] -> H_эпидемиолог <> O -> ~H.U`; `E_sargeras -> !V (вселенная M)`

Проверка онтологии:

- **Аксиома 2** — граница обратимости проходит точно: внутри S(M) обратимо всё (возрождение, откат патчем), в W необратимы время, отношения и пережитый сдвиг.
- **Аксиома 3** — событие симуляции как объект-след меняет понимание в W (эпидемиология); мем — совместный след сообщества.
- **Аксиома 1** — NPC без U неотличимы снаружи: приписывание понимания фиксируется только на стороне игрока.
