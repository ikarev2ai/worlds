# Стартрек: Возмездие

**Мир:** [«Звёздный путь»](../README.md)

**Автор:** Дж. Дж. Абрамс

**Тип:** Фильм

**Версия онтологии:** UWI v1.19

## Используемые события

**Естественный язык.**

Адмирал Маркус пробуждает Хана и использует его для подготовки войны. Хан размещает соратников в торпедах, атакует руководство Федерации и убивает Пайка. Кирк отказывается выполнить дистанционную казнь и сотрудничает с Ханом против военного корабля Маркуса, после чего Хан предаёт экипаж. Кирк погибает от радиации, спасая «Энтерпрайз». Маккой и Спок используют кровь Хана для восстановления его тела, а Хан возвращается в стазис.

## Контур UWI

```
H[marcus] -> H[khan][awakened]
H[khan] -> !H[pike]
H[kirk] -> MAY?(!H[khan]) = FALSE
H[marcus] -> MAY?(!H[enterprise_crew])
H[kirk] -> !H[kirk][radiation]
W/O[khan_blood] -> +H[kirk][restored]
(H[kirk][original] = H[kirk][restored]) = UNKNOWN
TRANSMIT?(H[khan].U,H[kirk][restored].U) = FALSE
REVERSIBLE?(~E[spock].U@t[1],E[spock].U@t[0]) = FALSE
```

## Вклад в общий стресс-тест

Добавляет отказ от внесудебного уничтожения, смерть и восстановление Кирка и различие биологического действия крови Хана и переноса `U`.
