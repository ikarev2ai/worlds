# Звёздный путь

**Мир:** [«Звёздный путь»](../README.md)

**Автор:** Дж. Дж. Абрамс

**Тип:** Фильм

**Версия онтологии:** UWI v1.19

## Используемые события

**Естественный язык.**

После гибели Ромула Неро и Спок из исходного будущего попадают в прошлое и создают альтернативную историю. Неро убивает отца Кирка, а позже уничтожает Вулкан красной материей. Молодой Кирк вступает в конфликт со Споком, но экипаж «Энтерпрайза» объединяется и останавливает «Нараду». Спок из исходной истории встречает молодого себя и помогает ему выбрать собственный путь.

## Контур UWI

```
E[nero]@M[prime]@t[future] -> E[nero]@M[kelvin]@t[past]
E[spock_prime]@M[prime]@t[future] -> E[spock_prime]@M[kelvin]@t[past]
E[nero] <> W/O[narada,red_matter] -> !W/P[vulcan] + !E[1..n]
E[spock_prime] <> H[kirk] + E[spock] -> ~H[kirk].U + ~E[spock].U
ACCESS?(E[spock_prime],E[spock].U) = FALSE
H[kirk] + E[spock] -> !W/O[narada] + !E[nero]
REVERSIBLE?(W@t[1],W@t[0]) = FALSE
```

## Вклад в общий стресс-тест

Вводит ветвление истории, необратимое уничтожение Вулкана и различие носителей двух версий Спока без внешнего сравнения `U`.
