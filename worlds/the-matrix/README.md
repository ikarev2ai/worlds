# «Матрица» — сенсорный изолятор

Люди телесно живут в капсулах, а их восприятие замкнуто на глобальную симуляцию, управляемую машинами.

## Основная часть

Человечество содержится в капсулах в естественном мире, но сенсорный контур каждого человека подключён к глобальной симуляции. Симуляцией управляют цифровые агенты (Архитектор) и программы-стражи внутри неё (Смит). Пробуждение — разрушение симуляции для конкретного человека и необратимый сдвиг его понимания при выходе в реальный мир.

Контур:

`H <> S(W)`, управляемый `A ∈ D` (Архитектор), стражи `E ∈ S(W)` (Смит). Пробуждение: `!S(W)` для H -> `~H.U` (выход в W).

Проверка онтологии:

- **Аксиома 2** — обратимость симуляции для системы и необратимость пережитого человеком сдвига `~H.U`.
- **Аксиома 1** — обитатель не может изнутри измерить подмену мира, пока не столкнётся с отказом контура.
