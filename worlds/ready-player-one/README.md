# Ready Player One — жизнь внутри симуляции

Человечество добровольно живёт в глобальной симуляции; умерший создатель продолжает менять понимание миллионов через след.

## Основная часть

Люди массово замыкают сенсорный контур на OASIS — глобальную симуляцию — по собственному выбору. Аватар обратим (гибель, «обнуление» — откат к новому старту), но решения внутри симуляции порождают необратимые ставки в реальном мире: долги, аресты, гибель тела. Умерший создатель OASIS оставляет пасхалку — след, годами меняющий понимание миллионов без единого живого контакта; ключ к ней — биография автора. Корпорация IOI борется не за содержимое симуляции, а за владение контуром взаимодействия целого поколения. Победитель вводит режим закрытия OASIS два дня в неделю — принудительный возврат людей в реальный мир.

Контур:

`H <> S(D)` (добровольно); `+D/O [пасхалка Халлидея] -> ~H.U (миллионы)`; решения в S(D) -> необратимые ставки в `W@t`

Проверка онтологии:

- **Аксиома 2** — обратимость аватара не отменяет необратимости базового времени.
- **Аксиома 3** — след умершего меняет `~H.U` массово и без контакта; расшифровка следа требует сближения с пониманием автора через его архив.
