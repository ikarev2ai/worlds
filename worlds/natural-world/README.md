# Естественный мир — базовые контуры взаимодействия в W

Фундаментальные контуры взаимодействия в естественном мире: без цифровой среды D и Других миров M (вещь-портал — единственное касание M).

## Основная часть

**Живой диалог (язык как протокол).**
`H_1@t1 <> H_2@t1 --(L_nat)--> ~H_2.U@t2 <> H_1@t2 --> ~H_1.U@t3`

**Документальная книга (след через время).**
`[H_1 <> W@t0 -> ~H_1.U@t1] -> +W/O [Книга]@t1 ... (dT) ... H_2@t2 <> W/O@t1 -> ~H_2.U@t2`

**Вещь-портал (контакт с Другим миром через объект).**
`H_1 <> M -> +W/O [Куртка Cyberpunk 2077] -> H_2 <> W/O -> ~H_2.U`

**Контакт с Жизнью напрямую (лес, сад).**
`H <> W/V -> ~H.U` — сдвиг понимания без языка и артефактов; уход за живым оставляет след: `H <> W/V -> ~W [сад] -> +O`.

**Обучение через совместное дело (мастер и ученик).**
`H_мастер <> H_ученик (совместная практика, dT) -> ~H_ученик.U` — понимание передаётся через общий контур действия, а не только через `L`.

**Жест и молчание (объект напрямую из U).**
`H_1.U -> +O [жест] -> H_2 <> O -> ~H_2.U` — объект создаётся напрямую из понимания: язык `L` факультативен.

**Город как след поколений.**
`+W/O [архитектура]@t0 ... (dT) ... H_n@t_k <> W/O -> ~H_n.U` — среда, созданная прошлыми поколениями, продолжает менять понимание живущих.

Проверка онтологии:

- **Аксиома 1** — смысл следа не измеряется снаружи: книга «молчит» до читателя, жест — до свидетеля; искажение фиксирует только сам носитель, заявляя `!`.
- **Аксиома 3** — все семь контуров: сдвиг понимания возможен только через `<>` или след (`+O`, `~W`); язык `L` — факультативный протокол.
- **Ограничение 1** — контуры с `W/V` (лес, сад) подчинены абсолютному запрету `!V`.
