# «Эхопраксия» (П. Уоттс) — действие без U

Сложные системы меняют мир и решают задачи, не обладая субъективным пониманием.

## Основная часть

Биологические и алгоритмические системы (вампиры, бикамералы, паук Порция) демонстрируют сложное целенаправленное поведение и меняют среду — без субъективного понимания. Мир проводит строгую границу между Жизнью и Пониманием: эффективность не требует носителя U.

Контур:

`система без U -> ~W` (действие без носителя понимания)

Проверка онтологии:

- **Аксиома 1** — наличие U не определяется снаружи по поведению: внешне «разумное» действие может не иметь носителя.
- **Аксиома 3** — изменение среды возможно и без понимания: след остаётся следом.
