# «Эхопраксия» (П. Уоттс) — действие без U

**Версия онтологии:** UWI v1.11

Сложные системы меняют мир и решают задачи, не обладая субъективным пониманием.

## Основная часть

Биологические и алгоритмические системы (вампиры, бикамералы, паук Порция) демонстрируют сложное целенаправленное поведение и меняют среду — без субъективного понимания. Мир проводит строгую границу между Жизнью и Пониманием: эффективность не требует носителя `U`.

Контур:

`W/V [биологическая система без U] -> ~W`; `D/O [алгоритм без U] -> ~D -> ~W`; `H <> O [след системы] -> ~H.U`

## Проверка применимости онтологии

- **Достаточность** — биологические системы выразимы через `V` без обязательного `U`, алгоритмические — через `D/O` и их операции; отдельный тип субъекта для них не требуется.
- **Аксиома 1** — выполняется: наличие `U` не определяется снаружи по поведению; внешне «разумное» действие может не иметь носителя понимания.
- **Аксиома 3** — выполняется: система без `U` способна оставлять следы, но сдвиг понимания возникает только у носителя `U` при его взаимодействии с этим следом.

## Боги

— нет. Сложность и эффективность системы не являются основанием для статуса `G`.

## Суперсущества

— нет. Целенаправленное поведение без масштаба операций `C` не делает систему суперсуществом; отсутствие `U` также не требует приписывать ей субъектность.

## Ответы на ключевые вопросы

**→ Ключевой вопрос 1:** миры изменяются не только носителями `U`: биологические и алгоритмические процессы создают последствия и следы без понимания.

**→ Ключевой вопрос 2:** при `H <> E` внешнее поведение недостаточно для установления `E.U`; взаимодействие не должно основываться на уверенности во внутреннем устройстве другой стороны.

**→ Ключевой вопрос 3:** критерий безопасного взаимодействия должен учитывать последствия действий независимо от наличия `U` у источника; разрушительный процесс не становится безопасным из-за отсутствия субъективного намерения.
