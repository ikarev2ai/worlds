# «Пламя над бездной» (В. Виндж) — коллективный носитель

**Версия онтологии:** UWI v1.14

Понимание одного субъекта распределено по стае организмов — гибель особи меняет само понимание.

## Основная часть

Среда естественного мира разделена на физические зоны с разными пределами вычисления. Носителем понимания Когтян выступает стая организмов: личность субъекта составлена из нескольких тел, и гибель одной особи напрямую меняет общее понимание стаи.

Контур:

`V_1..V_n -> E_tines.U`; `!V_1 -> ~E_tines.U`

## Проверка применимости онтологии

- **Достаточность** — топология `N → 1` локализует `E_tines.U` в контуре стаи; `!V_1 -> ~E_tines.U`, пока контур сохраняет носителя, а `!E_tines` означает его необратимую утрату.
- **Аксиома 1** — выполняется: понимание стаи является неделимым «чёрным ящиком» и ненаблюдаемо снаружи, хотя его носитель физически распределён.
- **Аксиома 2** — выполняется: гибель особи необратима; возникающий `~E_tines.U` следует изменению контура в `W@t` и не является откатом симуляции.
- **Аксиома 3** — применима: изменение общего понимания связано с физическим изменением носителя, а не с копированием `U` между особями.

## Ответы на ключевые вопросы

**→ Ключевой вопрос 1:** физические условия мира ограничивают возможные контуры вычисления и взаимодействия; носитель `U` может быть распределён по нескольким телам.

**→ Ключевой вопрос 2:** взаимодействие с иной сущностью требует учитывать границы её носителя: для Когтян собеседником является стая, а не изолированная особь, но `E_tines.U` остаётся недоступным прямому сравнению.

**→ Ключевой вопрос 3:** сохранение взаимодействия с коллективным носителем требует различать `!V_1`, изменение состава стаи и разрушение `E_tines` как субъекта.
