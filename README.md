# Understanding of World's Interaction

Понимание взаимодействия миров: формализм межмировых взаимодействий, эволюции понимания и сопряжения с иной Жизнью. Ядро проекта — язык **UWI (Understanding of World's Interaction)**.

**Текущая версия:** UWI v1.8

## Содержание

- `docs/manifest.md` — рабочий источник истины по онтологии UWI (вся правка — здесь)
- `docs/worlds.md` — миры: примеры и стресс-тесты онтологии
- `docs/system-prompt.md` — системный промпт, обязательный для сессий с AI-агентами
- `scripts/export_pdf.py` — экспорт markdown → PDF
- `AGENTS.md` — контракт для AI-агентов, работающих с проектом

## Экспорт в PDF

```bash
python3 scripts/export_pdf.py docs/manifest.md dist/UWI_v1.8_Manifest.pdf
```

Требуется только Python 3 + PyMuPDF (`pip install pymupdf`). Результат складывается в `dist/`.

## Суть в трёх строках

UWI задаёт онтологический алфавит из 14 понятий (миры W/D/M/P, жизнь V, субъекты H/A/E, ядро O/U/L/<>/S/T) и три операции (+ создание, ~ изменение, ! разрушение), поверх которых действуют три аксиомы: ненаблюдаемость пониманий, асимметрия обратимости симуляций и влияние через след во времени. Абсолютный запрет системы — уничтожение Жизни (!V).
