# Understanding of World's Interaction

Понимание взаимодействия миров: формализм межмировых взаимодействий, эволюции понимания и сопряжения с иной Жизнью. Ядро проекта — язык **UWI (Understanding of World's Interaction)**.

**Текущая версия:** UWI v1.16

## Содержание

- `ontology/manifest.md` — рабочий источник истины по онтологии UWI (вся правка формализма — здесь)
- `ontology/questions.md` — отдельный реестр открытых и закрытых вопросов онтологии
- `worlds/` — миры: стресс-тесты онтологии (каждый мир — отдельная директория; индекс — `worlds/README.md`, шаблоны — `worlds/template.md` и `worlds/template-work.md`; произведения-источники одного мира — `works/`)
- `ontology/system-prompt.md` — системный промпт, обязательный для сессий с AI-агентами
- `scripts/export_pdf.py` — экспорт markdown → PDF (техтребования: `docs/export-requirements.md`)
- `AGENTS.md` — контракт для AI-агентов, работающих с проектом
- `CONTRIBUTING.md` — правила совместной работы, проверки и подачи изменений

## Совместная работа

Добавлять миры и произведения, исправлять документацию и готовить изменения онтологии может любой участник — роль `H_author` для подготовки вклада не требуется. Изменения проходят общее рецензирование. Любое изменение манифеста требует новой версии и повторной проверки всех миров; выполняется оно только по явному указанию автора.

Порядок вклада описан в [CONTRIBUTING.md](CONTRIBUTING.md); требования для AI-агентов — в [AGENTS.md](AGENTS.md).

## Суть в трёх строках

UWI задаёт онтологический алфавит из 17 понятий (миры W/D/M/P, жизнь V, Бог/боги G, Душа An, субъекты H/A/E, ядро O/U/C/L/<>/S/T) и три операции (+ создание, ~ изменение, ! разрушение), поверх которых действуют три аксиомы: ненаблюдаемость пониманий, асимметрия обратимости симуляций и изменение понимания во времени самостоятельно или через след. Ключевые вопросы: как взаимодействуют миры; как взаимодействуют H <> A и H <> E; каковы критерии долгосрочного взаимодействия без взаимного уничтожения существ, Жизни и миров.
