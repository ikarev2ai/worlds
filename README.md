# Understanding of World's Interaction

Понимание взаимодействия миров: формализм межмировых взаимодействий, эволюции понимания и сопряжения с иной Жизнью. Ядро проекта — язык **UWI (Understanding of World's Interaction)**.

**Текущая версия:** UWI v1.11

## Содержание

- `ontology/manifest.md` — рабочий источник истины по онтологии UWI (вся правка — здесь)
- `worlds/` — миры: стресс-тесты онтологии (каждый мир — отдельная директория; индекс — `worlds/README.md`, шаблон — `worlds/template.md`)
- `ontology/system-prompt.md` — системный промпт, обязательный для сессий с AI-агентами
- `scripts/export_pdf.py` — экспорт markdown → PDF (техтребования: `docs/export-requirements.md`)
- `AGENTS.md` — контракт для AI-агентов, работающих с проектом

## Суть в трёх строках

UWI задаёт онтологический алфавит из 16 понятий (миры W/D/M/P, жизнь V, Бог/боги G, субъекты H/A/E, ядро O/U/C/L/<>/S/T) и три операции (+ создание, ~ изменение, ! разрушение), поверх которых действуют три аксиомы: ненаблюдаемость пониманий, асимметрия обратимости симуляций и влияние через след во времени. Ключевые вопросы: как взаимодействуют миры; как взаимодействуют H <> A и H <> E; каковы критерии долгосрочного взаимодействия без взаимного уничтожения существ, Жизни и миров.
