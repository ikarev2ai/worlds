# Spec Delta

## Purpose

Публикация всех материалов UWI в виде воспроизводимого статического сайта без ручного копирования содержимого и отдельного приложения-сервера.

## ADDED Requirements

### Requirement: Полнота публикуемых материалов
Сборка SHALL автоматически обнаруживать и публиковать онтологию, реестр вопросов, каталог, каждый мир и каждое произведение из текущих Markdown-источников. Шаблоны и служебные файлы OpenSpec MUST NOT считаться мирами или произведениями.

#### Scenario: В каталог добавлен мир с произведением
- **WHEN** в `worlds/<slug>/` существуют `README.md` и `works/<work-slug>.md` и выполняется новая сборка
- **THEN** сайт содержит отдельные HTML-страницы мира и произведения, доступные из каталога и страницы мира

#### Scenario: Полный исходный каталог
- **WHEN** выполняется сборка текущего репозитория
- **THEN** каждый `worlds/<slug>/README.md` и каждый `worlds/<slug>/works/*.md` имеет ровно одну соответствующую HTML-страницу, а `worlds/template.md` и `worlds/template-work.md` не публикуются как примеры

### Requirement: Сохранение исходного содержимого
HTML SHALL формироваться из Markdown без ручных копий и содержательных переписываний. Заголовки, абзацы, списки, таблицы, цитаты, акценты, inline code и блоки контуров UWI MUST сохранять содержимое и различимое представление.

#### Scenario: Страница с таблицей и контуром UWI
- **WHEN** исходный мир содержит таблицу произведений и блок с символами `<>`, `=>`, `[]`, `{}` и `@t`
- **THEN** HTML отображает таблицу как таблицу, контур как моноширинный блок, а спецсимволы остаются неизменными

#### Scenario: Обновление Markdown-источника
- **WHEN** после предыдущей сборки изменён только Markdown мира и выполнена новая сборка
- **THEN** обновлённый текст появляется на соответствующей HTML-странице без правки шаблонов или других HTML-файлов вручную

### Requirement: Автономный статический результат
Сборка SHALL создавать полный сайт в `dist/html/` из HTML, CSS, JavaScript и локальных данных. Чтение и навигация MUST работать через обычный статический HTTP-сервер без backend, базы данных и обязательных внешних CDN.

#### Scenario: Локальный показ без сети
- **WHEN** каталог `dist/html/` обслуживается локальным статическим HTTP-сервером при отключённой внешней сети
- **THEN** стартовая страница, онтология, каталог, миры, произведения и поиск работают без запросов к внешним сервисам

### Requirement: Проверка внутренних ссылок
Сборка SHALL преобразовывать относительные Markdown-ссылки между опубликованными документами в ссылки на их HTML-страницы и MUST проверять существование целей и якорей.

#### Scenario: Переход от мира к произведению
- **WHEN** читатель открывает ссылку из таблицы произведений мира
- **THEN** открывается HTML-страница соответствующего произведения, а не исходный `.md` и не ошибка 404

#### Scenario: Ссылка на удалённую страницу
- **WHEN** опубликованный Markdown ссылается на другой публикуемый документ, который отсутствует или не был сгенерирован
- **THEN** сборка завершается ошибкой с указанием исходного файла и нерабочей цели

### Requirement: Воспроизводимость и атомарность результата
Одинаковые исходники и конфигурация SHALL давать одинаковый набор маршрутов и содержимое страниц. Неуспешная сборка MUST NOT выдавать неполный каталог за готовый сайт или оставлять страницы удалённых источников.

#### Scenario: Повторная сборка без изменений
- **WHEN** сборка дважды выполняется на неизменном репозитории
- **THEN** обе версии имеют одинаковые маршруты и содержимое HTML, CSS, JavaScript и поисковых данных

#### Scenario: Ошибка преобразования документа
- **WHEN** хотя бы один обязательный источник не удаётся прочитать или преобразовать
- **THEN** команда возвращает ненулевой статус, сообщает причину и не заменяет последний успешный результат неполной сборкой
