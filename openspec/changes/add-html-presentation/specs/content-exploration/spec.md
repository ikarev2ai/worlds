# Spec Delta

## Purpose

Удобное чтение и исследование онтологии и примеров UWI людьми, которые не знают структуру репозитория и не используют его инструменты разработки.

## ADDED Requirements

### Requirement: Основная навигация
Сайт SHALL предоставлять со стартовой страницы доступ к онтологии, реестру вопросов и каталогу миров. Каталог SHALL вести к каждому миру, а страница мира — ко всем его произведениям и обратно к каталогу.

#### Scenario: Первое знакомство с проектом
- **WHEN** читатель открывает стартовую страницу
- **THEN** он видит краткое представление UWI, текущую версию и явные переходы к онтологии, вопросам и всем мирам

#### Scenario: Исследование произведения
- **WHEN** читатель открывает произведение со страницы мира
- **THEN** он может вернуться к родительскому миру и перейти к другим произведениям того же мира без использования истории браузера

### Requirement: Локальный поиск
Сайт SHALL искать по названиям и текстам онтологии, вопросов, миров и произведений на устройстве читателя. Поиск SHALL учитывать русский текст без чувствительности к регистру и MUST NOT отправлять запросы во внешние сервисы.

#### Scenario: Поиск мира по названию
- **WHEN** читатель вводит название существующего мира в другом регистре
- **THEN** среди результатов есть этот мир с работающей ссылкой на его страницу

#### Scenario: Поиск по тексту произведения
- **WHEN** читатель вводит фрагмент текста, который есть только в произведении
- **THEN** результат ведёт на страницу произведения и показывает достаточный контекст для распознавания совпадения

#### Scenario: Поиск без совпадений
- **WHEN** запрос отсутствует во всех опубликованных материалах
- **THEN** сайт показывает понятное сообщение об отсутствии результатов и не выводит ошибку скрипта

### Requirement: Чтение на разных экранах
Страницы SHALL быть читаемыми на desktop и mobile без горизонтальной прокрутки всей страницы. Длинные контуры UWI и широкие таблицы MUST сохранять доступное содержимое через локальную прокрутку или перенос, не обрезаясь.

#### Scenario: Мир с широкой таблицей на телефоне
- **WHEN** страница мира с таблицей произведений открыта при ширине viewport 360 px
- **THEN** основной текст и навигация помещаются по ширине экрана, а все столбцы таблицы доступны без обрезки

#### Scenario: Длинный контур UWI
- **WHEN** опубликованный контур не помещается по ширине экрана
- **THEN** читатель может просмотреть его целиком в пределах блока без потери символов и без горизонтальной прокрутки всей страницы

### Requirement: Прямые ссылки и якоря
Каждая страница и значимый заголовок SHALL иметь стабильный адрес для прямого открытия и передачи другому человеку. Повторная сборка без переименования исходника MUST сохранять его маршрут.

#### Scenario: Ссылка на раздел аксиомы
- **WHEN** читатель открывает прямую ссылку на якорь раздела онтологии
- **THEN** браузер показывает нужный раздел с сохранённым заголовком и содержимым

#### Scenario: Прямое открытие произведения
- **WHEN** другой человек открывает полученный URL произведения на статическом сайте
- **THEN** сервер возвращает страницу произведения с навигацией к родительскому миру

### Requirement: Доступность без клиентского JavaScript
Основное содержимое и переходы между страницами SHALL оставаться доступными при отключённом JavaScript. JavaScript MAY добавлять поиск и вспомогательные элементы, но MUST NOT быть единственным способом чтения материалов.

#### Scenario: Чтение с отключённым JavaScript
- **WHEN** читатель открывает сайт с отключённым JavaScript
- **THEN** он может прочитать онтологию и любой мир, перейти к произведению и вернуться в каталог обычными ссылками
