# Proposal

## Why

Сейчас онтология и все примеры доступны только как набор Markdown-файлов в репозитории. Для демонстрации проекта людям нужен удобный read-only сайт с полным содержимым, навигацией и поиском, который не требует от читателя понимания структуры репозитория.

## What Changes

- Добавить генерацию статического HTML-сайта из существующих `ontology/manifest.md`, `ontology/questions.md`, `worlds/README.md`, всех `worlds/<slug>/README.md` и всех `worlds/<slug>/works/<work-slug>.md`.
- Добавить стартовую страницу, страницы онтологии и вопросов, каталог миров, отдельные страницы миров и произведений.
- Обеспечить навигацию между миром и его произведениями, рабочие внутренние ссылки и якоря, закреплённую шапку, адаптивное отображение текста, таблиц и многострочных контуров UWI.
- Оставить в HTML-таблице произведений только название со ссылкой и вклад в стресс-тест; скрывать технические метаданные и дублирующие разделы, не изменяя исходный Markdown.
- Упорядочить открытые вопросы и в `ontology/questions.md`, и на сайте: заметный заголовок вопроса, затем «Естественный язык» и «Контур UWI» без изменения формулировок и статусов.
- Показывать на вкладке «Миры» только сгенерированный «Каталог всех миров» без исходной служебной таблицы; добавить предупреждение о спойлерах, оставить в карточках только названия миров и применять контрастную тёмную подсветку ко всем inline- и блочным терминам UWI.
- Добавить локальный поиск по опубликованным материалам без внешнего поискового сервиса.
- Проверять при сборке полноту набора источников и корректность внутренних ссылок, чтобы новые миры и произведения не терялись.
- Сохранить Markdown-файлы единственным источником содержимого и не дублировать их вручную. Не менять манифест и версию онтологии; в корневых описаниях миров меняется только оформление контуров, а в `ontology/questions.md` — только структура открытых вопросов без содержательных правок.
- Не изменять существующий PDF-экспорт. Добавить GitHub Actions workflow для публикации статической сборки на GitHub Pages; локальный показ и размещение в подкаталоге должны сохраняться.

## Capabilities

### New Capabilities

- `static-content-publishing`: воспроизводимое преобразование всех Markdown-источников UWI в полный автономный статический сайт с проверкой полноты и ссылок.
- `content-exploration`: навигация, поиск и чтение онтологии, миров и произведений на desktop и mobile без изменения исходных материалов.

### Modified Capabilities

— нет

## Impact

Появятся отдельные исходные файлы генератора, HTML-шаблоны, стили, клиентский JavaScript и конфигурация сборки. Сгенерированный сайт будет размещаться в игнорируемом `dist/html/`; `ontology/manifest.md` и `scripts/export_pdf.py` не меняются этим изменением. В `worlds/` меняется только оформление контуров UWI на многострочное, а в `ontology/questions.md` — структура открытых вопросов, без содержательных правок и смены версии. Потребуется явно зафиксировать новые зависимости и команды сборки в выбранном инструментарии. GitHub Actions будет использовать эти же команды и публиковать `dist/html/` через GitHub Pages.
